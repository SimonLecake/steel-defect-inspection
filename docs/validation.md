复现实验应同时保留：数据版本与划分、权重校验值、代码提交、依赖版本、随机种子、训练配置、评估命令、各类别指标及硬件信息。

## 已知工程限制

- VLM `confidence=1.0` 是占位值，不能用于可靠性排序。
- API 调用或 JSON 解析失败可能得到空检测框，需要增加明确的失败状态。
- 当前 VLM 坐标适配依赖模型名；新服务必须确认返回坐标约定。
- 审核仅记录当前状态和备注，没有逐框标注编辑、审核历史与审核人。
- 全局检测器适合本地演示，尚未实现多用户配置隔离。
- 问题样本导出需要后续人工修正标签，不是自动生成可信真值。
- 类别名称在多个实验脚本中维护，变更类别需同步检查。
- 检测结果需要保留原始图片文件才能追溯；当前没有对象存储或清理策略。
