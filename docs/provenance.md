# 项目来源与公开范围

本仓库由本地“项目实战：AI质检 / CASE-AI质检”学习项目整理而来，用于展示钢铁表面缺陷检测的技术路线、工程结构与实践成果。它包含对既有实战代码的整理，不将所有底层代码或模型研究归为仓库维护者原创。

本次作品集整理包括：中英文项目说明、架构展示图、数据与模型准备指南、环境依赖整理、批量推理兼容性调整、基础回归检查及持续集成配置。

## 公开内容

- 检测工作台、引擎封装、记录管理、导出与实验脚本。
- 网络与数据配置示例、工程说明、自动检查。
- 自行编写的项目流程示意图；示意图不代表实际检测结果。

## 未随仓库分发的内容

- 原始课程 PDF、压缩包和课堂笔记。
- 数据集原图、标注、训练权重、训练日志与原始实验产物。
- 本地数据库、审核备注、用户上传图片与 API 密钥。

## 第三方组件

模型与应用依赖包括 Ultralytics / YOLO、PyTorch、Gradio，以及通过 OpenAI 兼容客户端访问的视觉语言模型服务。数据集、模型权重和第三方依赖分别遵循其各自的来源条款。

当前没有为整个整理仓库新增统一开源许可证：原始实战材料的完整授权信息尚未附于仓库。公开展示不表示对所有第三方材料作出重新授权。后续补充准确的课程来源、作者信息及授权说明后，可进一步完善本页。
